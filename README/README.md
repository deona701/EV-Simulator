## Information About My Project
### EV Simulator
This project began as something that seemed almost impossible. I had no knowledge about 
using Qt Creator, and I only used it because when researching, I found out that it was 
an industry standard for projects like these. On my first day, I spent over 6 hours 
working on the project, and then many more hours after it. It was absolutely 
stressful, and I thought I'd never get it, but somehow, I managed.  
I'm grateful I did, because I learned a lot from it.  
This is my first project using Qt Creator, and certainly not my last.

### AI Usage
AI was used during the planning phase to create a project framework. The framework did not 
contain the code, but only provided a step by step structure for what to do during development.  
All final implementation decisions, code integration, testing 
and modifications were done by me.
